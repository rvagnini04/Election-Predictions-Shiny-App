# Election-Predictions-Shiny-App
This repository includes the R code to a Shiny app titled "Improved Methods of the U.S. Presidential Election Predictions." 

Note that the `finalprojdata.qmd` file contains all the data collection and manipulation that is saved to the `full_data.rds` file in the `electionpredictions` folder. The `app.R` file (in the `electionpredictions` folder) is where the Shiny App is created (and it references the `full_data.rds` file for the data sourcing).
